# Open Regulatory Corpus — Bronze → Silver

A public-only, machine-readable corpus of AI, privacy, cybersecurity, financial, and health regulations — cleaned and chunked for retrieval. **38 public frameworks → 58 raw documents (43 MB) → 1,519 citation-ready chunks across 54 documents.**

Generated by [dataengineergaurav/open-regulatory-corpus](https://github.com/dataengineergaurav/open-regulatory-corpus), which re-runs monthly and keeps every run in its Bronze landing zone. Source of truth: [`data/sources.json`](https://github.com/dataengineergaurav/open-regulatory-corpus/blob/main/data/sources.json) (46 entries: 38 public + 8 paywalled).

> **Not legal advice.** A convenience copy of public sources. Verify against the authoritative URL for every framework.

## Schema

| Column | Type | Meaning |
|---|---|---|
| `framework_id` | string | Framework stem (`NIST-CSF2`); a `_pdfN` suffix marks a secondary document for the same framework |
| `chunk_id` | string | Stable id, `{framework_id}-{index}` |
| `text` | string | The chunk (512-token window, 50-token overlap) |
| `source` | string | Bronze path the chunk came from |
| `kind` | string | `pdf` or `html` |
| `token_est` | float | Approximate tokens (`words × 1.33`) |
| `sha256` | string | Content hash of the source document (groups its chunks) |

## Use

```python
from datasets import load_dataset

ds = load_dataset("GauravGurjar/open-regulatory-corpus")["train"]

# filter by framework
fda = ds.filter(lambda x: x["framework_id"] == "FDA-AI-MD")          # 80 chunks

# all documents for a framework (primary + secondary PDFs)
sox = ds.filter(lambda x: x["framework_id"].split("_pdf")[0] == "SOX")  # 226 chunks
```

## Gaps (documented, not hidden)

Seven public frameworks currently yield **0 chunks**: `EU-AI-ACT` and `GDPR` (EUR-Lex serves a JavaScript shell), `HIPAA`, `HHS-PART2`, `CMMC` (WAF HTTP 403), `IL-AIVIA` (timeout), `BR-LGPD` (URL returns an HTML wrapper, not a PDF). Every source's outcome (`ok` / `skipped_public_only` / `error`) is recorded in the repo's `manifest.jsonl`, and gaps are tracked release-over-release. Details: [FAQ](https://github.com/dataengineergaurav/open-regulatory-corpus/blob/main/docs/FAQ.md#why-are-some-frameworks-empty).

## Provenance

Every row is traceable end to end: `chunk_id` → `source` (Bronze path) → `manifest.jsonl` (`sha256_raw`, byte count, fetch time) → authoritative `url` → `sources.json`. Cite `framework_id`, `chunk_id`, and `source` for any answer.
